# Bot Runner Source Modes

Runner 数据源可以理解成：Bot 后台运行时，运行状态从哪里来。

现在支持三个模式：

## mock

默认模式。

它使用本地模拟数据更新 Bot 的心跳、延迟、盈亏和净敞口。适合 VPS 先部署、验证管理台、验证风控、验证备份恢复。

不会真实下单。

## readonly

预留给真实只读 Runner。

目标是后续接入真实行情和账户数据，但仍然不下单。这个阶段适合检查：

- 行情是否能稳定读取
- 子账户是否能正确识别
- 仓位和余额是否能正确同步
- 告警和熔断是否能及时显示

当前还没有接真实数据源，所以会显示“只读数据源尚未接入真实行情/账户”。

## live

预留给真实交易 Runner。

目标是后续真正下单和撤单。这个模式上线前必须补齐：

- 服务端权限
- 服务端风控
- 真实行情源
- 真实下单执行
- 真实撤单执行
- 更严格的审计日志
- 小额度白名单

当前还不会真实下单，所以会显示“实盘数据源尚未接入真实交易 Runner”。

## VPS 配置

在 `.env` 里设置：

```text
BOT_RUNNER_SOURCE=mock
```

后续接只读 Runner 时改成：

```text
BOT_RUNNER_SOURCE=readonly
```

真正接实盘 Runner 时才改成：

```text
BOT_RUNNER_SOURCE=live
```

建议上线顺序：

1. `mock`：先确认 VPS 部署、页面、风控、备份都正常。
2. `readonly`：接真实行情和账户，只看不下单。
3. `live`：小额度、白名单、人工盯盘后再开放。
